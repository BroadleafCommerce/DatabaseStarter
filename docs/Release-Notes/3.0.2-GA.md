# Broadleaf DatabaseStarter 3.0.2-GA

_Released on September 5, 2024_

This is the 2nd patch release for the Broadleaf DatabaseStarter 3.0.x module. This version requires Broadleaf Framework version 7.0.2-GA.

## An at-a-glance view of the issues that were closed in this release:

### Enhancements(1)
- Updated `DatabaseAutoConfiguration.java` to use `StringUtils.hasText()` instead of `StringUtils.isEmpty()` because it has been deprecated since Spring 5.3

**Total Resolved Issues: 1**
